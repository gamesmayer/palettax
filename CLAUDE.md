# Working agreements

Unless the user explicitly says otherwise in their prompt:

- Don't test features visually (e.g. launching the app, taking screenshots, driving the UI). The user will do this themselves.
- Don't run prettier or eslint. The user will do this themselves.

# UI aesthetic

The UI follows a Windows 95 look, built with the [@react95/core](https://react95.io) component library. Keep new UI consistent with this style.
