## Features

- Import one or several color palettes at once, each opening in its own tab.
- Several palettes can be open at the same time.
- Export the active palette in any of the supported formats.
- Add colors (with a color picker and an optional name), remove them, and reorder them (by dragging or with the ↑/↓ buttons) within the active palette.

## Supported formats

### JASC-PAL (`.pal`)

Text format used by Paint Shop Pro. Does not support color names.

```
JASC-PAL
0100
4
255 0 0
0 255 0
0 0 255
255 255 255
```

### GIMP Palette (`.gpl`)

GIMP's text format. Supports a palette name, column count, and a name per color.

```
GIMP Palette
Name: My Palette
Columns: 4
# Generated by Palettax
255   0   0	Red
  0 255   0	Green
  0   0 255	Blue
255 255 255	White
```

### Hex List (`.txt`)

Plain text list, one hexadecimal color per line. Does not support color names.

```
#FF0000
#00FF00
#0000FF
#FFFFFF
```

### CSS Custom Properties (`.css`)

Generates a `:root` block with one variable per color. On import, only the hexadecimal values are read; the variable name is not preserved (imported colors have no name).

```
:root {
  --color-1: #FF0000;
  --color-2: #00FF00;
  --color-3: #0000FF;
  --color-4: #FFFFFF;
}
```

## Requirements

- Node.js 20 (LTS) and npm.

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Opens the app with hot-reload on top of Electron.

## Tests

```bash
npm test
```

Runs the Jest suite over the pure functions in `src/shared` (parsers/serializers for `.pal`/`.gpl`/`.txt`/`.css` and color utilities), located in `/test` mirroring `src/shared`.

## Local build

```bash
npm run build:mac   # generates a .dmg in release/
npm run build:win   # generates an .exe (NSIS) installer in release/
```

To use a custom icon, place `icon.icns` and `icon.ico` in `build/` (see `build/README.md`).

## Publishing a release (GitHub releases)

When a `vX.Y.Z` tag is pushed, the `.github/workflows/release.yml` workflow builds the app on Windows and macOS and publishes the installers to the repository's Releases section:

```bash
npm version patch   # or minor / major
git push --follow-tags
```

The installers will be available for download from Releases without needing to build locally.

## Usage

1. **Import**: click "Import" (or "+ Import" in the tab bar) and select one or more `.pal`/`.gpl`/`.txt`/`.css` files. Each one opens in a new tab.
2. **Switch palette**: click the corresponding tab. You can close a tab with the "×".
3. **Add color**: with the desired tab active, click "Add color", pick a color with the picker and, optionally, give it a name.
4. **Remove color**: click the "✕" on the color to remove.
5. **Reorder colors**: drag a color to its new position, or use the ↑/↓ buttons.
6. **Export**: with the active palette ready, pick one of the available formats (`.pal`, `.gpl`, `.txt`, `.css`) from "File → Export Palette as" and choose where to save it.

## Project structure

```
src/
├── main/       # Electron main process (windows, menu, file dialogs)
├── preload/    # secure bridge between main and renderer
├── shared/     # pure code: data models, .pal/.gpl/.txt/.css parsers/serializers, utilities
└── renderer/   # React UI (tabs, color list, dialogs)
test/           # Jest tests, mirroring src/shared
```
